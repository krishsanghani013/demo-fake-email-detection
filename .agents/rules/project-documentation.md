# Mandatory Project Documentation Rule

Whenever you make any modifications, feature additions, refactors, UI updates, or bug fixes to this codebase:

1. **YOU MUST UPDATE `PROJECT_DOCUMENTATION.md`** in the repository root in the same turn.
2. Ensure the following sections in `PROJECT_DOCUMENTATION.md` are kept up to date:
   - File map & directory structure
   - Risk engine weights and scoring rules (if touched)
   - Data models & schemas (if modified)
   - UI component list and role descriptions
   - Verification suite tests
   - Project Changelog (add a new entry documenting the date, author, and bullet points of what changed)
3. Never conclude a task that modifies the project without synchronizing `PROJECT_DOCUMENTATION.md`.
